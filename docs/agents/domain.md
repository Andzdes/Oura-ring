# Domain Docs

This repository uses a single-context domain-documentation layout.

## Before exploration

Read `CONTEXT.md` and relevant ADRs under `docs/adr/` when they exist.

Their absence requires no setup action. `/domain-modeling` creates them when shared
terminology or a durable decision emerges.

## Vocabulary

Use the glossary's terms in Task titles, descriptions, tests, and implementation
discussion.

A missing concept signals either vocabulary drift or work for `/domain-modeling`.

## ADRs

Surface a conflict with an existing ADR explicitly before proposing a contradictory
direction.
